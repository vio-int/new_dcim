# DCIM PoC Frontend

Vue 3 + Vite dashboard with real-time charts.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Environment Variables

Copy `.env.example` to `.env`:

- `VITE_API_URL` - Backend API URL
- `VITE_WS_URL` - WebSocket URL
